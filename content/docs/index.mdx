## What is GenomeJS?

GenomeJS is a reactive design-token compiler for frontend interfaces.

Declare primitives, tokens, and runtime context. GenomeJS discovers dependencies, resolves values safely, and expresses the result as CSS custom properties.

## Core packages

- `@genomejs/core`
- `@genomejs/react`
- `@genomejs/vue`
- `@genomejs/svelte`

## Installation

```bash
npm install @genomejs/core
```
